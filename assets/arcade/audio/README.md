Fireworks 08: Web Audio decode, 48 kHz, 6.024 s; RMS/высокочастотная энергия по окнам 5 ms, поиск прироста энергии относительно предыдущих 75 ms. Основные пики RMS: 0.245, 0.800, 1.650, 2.090, 2.645 s; более слабый начальный импульс — 0.035 s. Фронты максимального локального прироста RMS: **0.020, 0.240, 0.800, 1.645, 2.090, 2.645 s**. Первый сопровождается небольшим залпом; поздний затухающий треск не считается новыми крупными хлопками. Конфигурация — `client/src/arcade/fireworksCues.ts`.

Анимация читает позицию того же AudioContext, на котором запланирована дорожка, с компенсацией вывода через getOutputTimestamp, если доступен. Отрицательный pre-roll 0.5 s позволяет ракете подняться перед первым хлопком. При mute те же метки воспроизводятся по монотонным часам. Задержка загрузки не сдвигает метки относительно начала записи.
