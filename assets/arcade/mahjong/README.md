# Mahjong face artwork

`riichi/*.svg`: unchanged Regular SVGs by **FluffyStuff**, downloaded directly from
https://github.com/FluffyStuff/riichi-mahjong-tiles at revision
`26e127ba2117f45cdce5ea0225748cc0cfad3169`.
Upstream dedicates all assets to the public domain under **CC0 1.0**. Commercial use
and modification are permitted, without an attribution requirement. Original notice:
[riichi/LICENSE.md](riichi/LICENSE.md); source paths and SHA-256: [riichi/SOURCE.json](riichi/SOURCE.json).
Terms: https://creativecommons.org/publicdomain/zero/1.0/ . No endorsement is implied.

Mapping: Pin1–9 = circles, Sou1–9 = bamboo, Man1–9 = characters;
Ton/Nan/Shaa/Pei = east/south/west/north;
Chun/Hatsu/Haku = red/green/white dragon. **Haku is intentionally a blank face**,
as in Japanese riichi; its empty SVG is not a failed download.
No red-five variants, flowers or seasons were imported. The repository has no flower/season art.

`ghosty/sun.svg` and `ghosty/moon.svg` are original Ghosty vector drawings, not
FluffyStuff assets. They preserve the prototype's existing Sun/Moon IDs 34/35,
with the owner's explicit approval, rather than relabelling them as flowers/seasons.
The shared 3D base, bevel, shadow and selection remain Ghosty CSS; SVGs draw only the faces.
