# Локальный шрифт

Nunito variable upright, веса 200–1000, с кириллицей. Лицензия SIL Open Font License 1.1 находится рядом в OFL.txt: разрешено включать шрифт в игру и распространять вместе с ней.

Источник: https://github.com/google/fonts/tree/main/ofl/nunito
Скачано 2026-10-01 без изменений. Файл Nunito[wght].ttf переименован в Nunito.ttf для удобного URL.

Подключение и веса: client/src/styles/variables.css. Браузер получает файл из проекта, внешние CDN не используются.
